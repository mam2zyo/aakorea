# 관리자 콘솔 아키텍처 (Admin Console)

관리자 전용 기능과 운영자 환경을 독립적으로 관리합니다.

## 1. 진입점 및 부트스트랩 (Entry Point)
관리자 콘솔은 `admin.html` → `src/admin-main.jsx`를 통해 독립적으로 부트스트랩됩니다.

- **전용 환경**: 보안상의 이유로 공개 사이트와 진입 경로가 완전히 분리되어 있으며, 관리자 전용 라이브러리(리치 텍스트 에디터, 대량 데이터 그리드 등)를 포함합니다.
- **핵심 진입점**: `src/admin/app/AdminApp.jsx`가 운영자 세션, 권한 가드(Guard), 어드민 테마를 총괄합니다.
- **별칭 지원**: 모든 관리자 코드는 `@/admin/...` 경로를 통해 구조화됩니다.

## 2. 관리자 셸 (Admin Shell)
관리자 전용 레이아웃은 일관된 작업 환경을 제공하기 위해 다음과 같이 구성됩니다.

- **Sidebar (Navigation)**: 주요 도메인(그룹, 지역연합, 콘텐츠, 공지사항) 메뉴를 제공합니다.
- **Topbar**: 현재 로그인한 운영자 정보와 테마 설정을 제공합니다.
- **Layout Logic**: 관리자 대시보드는 상시 로그인이 필요하며, 세션 만료 시 로그인 페이지로 자동 리다이렉트됩니다.

## 3. 관리자-공개 사이트 교차 탐색
MPA 분리 아키텍처에 따라, 관리자 도구에서 공개 사이트 기능을 호출할 때는 다음과 같은 규칙을 따릅니다.

- **미리보기 & 홈 이동**: SPA 내부 라우팅 대신 물리적인 페이지 이동(MPA)을 수행해야 합니다.
- **구현 원칙**: 관리자 라우터는 공개 사이트 경로를 알지 못하므로, **`window.open(url, '_blank')`**를 사용하여 새 탭에서 실제 공개 페이지를 로드합니다. (테마 미리보기, 공지 미리보기 등)

## 4. 그룹 및 모임 관리 (Group Management)
가장 복합적인 로직을 담고 있는 영역으로, **"목록 중심 + 대형 시트(Sheet)"** 구조를 따릅니다.

### 데이터 모델 구조
- **Group**: 물리적인 모임 그룹의 본체 (이름, 지역연합, 이메일 등).
- **Meeting**: 그룹 내에서 특정 요일/시간에 열리는 개별 세션.

### 관리 프로세스
- **수정**: 목록에서 그룹을 클릭하면 대형 시트가 열리며, `shared/ui` 및 `admin/ui` 컴포넌트를 사용하여 정보를 정밀하게 수정합니다.
- **상태 동기화**: `src/admin/features/*/api`를 통해 백엔드와 통신하며, 결과는 공개 사이트 API(`src/shared/api`)를 통해 검색 결과에 즉시 반영됩니다.
