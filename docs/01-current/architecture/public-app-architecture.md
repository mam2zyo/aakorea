# 공개 사이트 아키텍처 (Public Site)

일반 방문자를 위한 검색 및 안내 기능을 고성능 MPA 환경으로 제공합니다.

## 1. 진입점 및 부트스트랩 (Entry Point)
공개 사이트는 `/` 주소의 `index.html` → `src/public-main.jsx`를 통해 부트스트랩됩니다.

- **번들 최적화**: 관리자 전용 라이브러리(Rich Editor 등)를 제외하여 번들 크기를 최소화하고 초기 로딩 성능을 확보합니다.
- **핵심 진입점**: `src/public/app/PublicApp.jsx`가 사이트 전반의 테마 적용 및 라우팅을 담당합니다.

## 2. 모임 찾기 서비스 (Meeting Search)
사용자가 가장 많이 사용하는 모임 검색 기능을 위해 최적화된 로직을 담고 있습니다.

### 핵심 기능
- **메모리 기반 검색**: 한 번 로드된 데이터(`rawMeetings`)는 클라이언트 가용 메모리에 유지되며, 이후의 세부 필터링(요일, 유형, 키워드)은 백엔드 요청 없이 즉시 처리됩니다.
- **상태 중심 제어**: `useMeetingSearch` 훅을 통해 복잡한 필터 상태와 결과를 중앙 집중식으로 관리합니다.

### UI 레이아웃 및 UX 전략
- **상태 기반 UI 분기 (IDLE vs ACTIVE)**: 검색 전에는 메인 검색 폼(지역 선택/가까운 모임)을 노출하고, 검색 후에는 해당 폼을 숨긴 뒤, 진행 중인 상태에 맞춘 스티키(Sticky) 제어 바와 액션 버튼(초기화, 상세 조건 모달)만 노출해 모바일 화면 공간을 최적화합니다.
- **집약형 2행 리스트 (Condensed List)**: 데이터 밀도를 높이기 위해 모임 정보(요일/시간/그룹명/유형 뱃지 및 주소/거리)를 2줄로 압축하여 한 번에 여러 결과를 탐색하기 쉽게 개선했습니다.
- **모달 방식 상세 필터**: 인라인 노출로 인해 스크롤 공간을 차지하던 상세 검색(요일, 유형, 지역연합, 키워드 등)을 별도 모달 팝업으로 분리해 모바일 조작 편의성을 높였습니다.

### 아키텍처 특징
- **Shared Kernel 활용**: 서버 통신은 `@/shared/api`를 사용하며, 기초 UI는 `@/shared/ui`를 통해 일관된 디자인을 유지합니다.
- **도메인 격리**: 운영 콘솔의 어떠한 코드도 공개 사이트 영역으로 임베딩(Embedding)될 수 없도록 강제합니다.

## 3. 테마 및 디자인 시스템
실시간 테마 적용 및 드래프트 미리보기를 지원합니다.

- **테마 미리보기**: 관리자 배포 전 기능을 지원하기 위해 URL 파라미터를 통한 실시간 테마 오버라이딩을 제공합니다. (`src/shared/utils/themeDocument.js` 참조)
- **토큰 기반 스타일링**: 모든 컴포넌트는 하드코딩된 색상 대신 `@/shared/styles`의 디자인 토큰을 사용하여 일관된 브랜딩을 유지합니다.
