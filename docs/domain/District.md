# District

## 이 문서의 역할

이 문서는 `District`의 현재 모델 의미와 필드를 정리한다.

이 문서에 포함하지 않는 내용:

- 제품 범위 판단
- 사용자 행동 흐름
- API 요청 / 응답 JSON 상세

---

## 현재 모델 의미

`District`는 **지역연합**이다.

현재 구현에서 `District`는 아래 역할을 가진다.

- 그룹의 소속 기준
- 운영 목록과 정렬의 상위 기준
- 공개 화면에서 그룹의 지역연합 이름 표시

현재는 트리 구조나 상하위 조직 모델을 갖지 않는다.

---

## 현재 핵심 필드

- `id`
- `name`

### 필드 메모

- `name`은 지역연합 이름이다
- 공백 이름은 허용하지 않는다

---

## 현재 규칙

- `District`는 독립 관리 화면에서 CRUD한다
- 연결된 `Group`이 있으면 삭제 시 `409 Conflict`를 반환한다

---

## 공개 흐름에서의 의미

- 모임 상세 모달에서 `Group`의 지역 문맥을 보여 준다

---

## 운영 흐름에서의 의미

- 그룹 생성 / 수정 시 반드시 선택하는 상위 기준이다
- 현재 운영에서는 단순하지만, `Group` 화면에 흡수하지 않고 독립 관리 대상으로 유지한다

---

## 관계

- 하나의 `District`는 여러 `Group`을 가진다

---

## 제외 / 보류

현재는 아래를 지원하지 않는다.

- 지역연합 트리 구조
- 상위 / 하위 조직 관계
- 추가 메타데이터 필드

---

## 관련 API 문서

- API 상세 스펙은 Swagger UI의 General Services 관리 부분을 참고하십시오.
