# PRODUCT_SCOPE

## 이 문서의 역할

이 문서는 현재 MVP 범위를 **실제 구현 기준**으로 다시 정리한다.

---

## 현재 MVP의 핵심 목표

현재 MVP의 목표는 다음과 같다.

> 1. 방문자는 다양한 방법으로 모임을 검색할 수 있다.
> 2. 방문자는 그룹 문맥 안에서 연락처 정보 혹은 장소 및 이동에 관한 정보를 찾을 수 있다.
> 3. 운영자들은 주어진 역할에 따라 권한을 세분화해서 부여받을 수 있다.
> 4. 운영자들은 그룹 및 모임 정보와 공개 사이트 컨텐츠를 직접 관리한다.
> 5. 운영자들은 주요 엔티티의 변경 이력을 추적할 수 있다.

---

## 현재 포함 범위

### 1. 공개 사용자 흐름

- 홈, 안내 페이지, 공지 조회
- 지역 / 요일 기준 모임 검색
- 현재 위치 기준 가까운 모임 검색
- `/meetings` 안의 같은 페이지 모달 상세
- `/groups/:id` 직접 진입으로 같은 그룹 상세 열기
- 같은 그룹의 다른 모임 리스트 확인
- 선택된 모임 기준 장소 / 연락처 확인
- 대화면 카카오 지도 표시
- 선택된 모임 기준 카카오맵 위치 보기 / T map 길안내 링크
- 게시된 공개 사이트 테마 반영과 미리보기 query 유지

### 2. 운영자 흐름

- 로그인 / 로그아웃 / 세션 확인
- 지역연합 관리
- 그룹 / 대표 연락처 / 모임 관리
- 콘텐츠 / 공지 관리 (Rich Text 에디터 통합)
- 첨부파일 업로드 및 공지/콘텐츠 연동
- 운영자 권한 세분화 (Role / Permission 모델)
- 공개 사이트 테마 드래프트 저장 / 게시 / 롤백
- 테스트 도구에서 HTML normalize와 정제 JSON import preview / apply / reset
- 테스트 도구에서 모임 좌표 dry-run / backfill

### 3. 관리자 UX 범위

- 그룹 목록 중심 진입
- 그룹 생성 2단계 모달
- 그룹 수정 읽기 중심 시트 + 섹션별 서브 모달
- 계정 설정에서 브라우저 로컬 admin theme preference
- `/admin/public-theme`에서 공개 사이트 preset theme 관리
- `/admin/overview`에서 테스트 도구 분리

## 현재 범위에서 명확히 제외한 것

### 그룹 / 콘텐츠 확장

- 그룹 변경 이력

### 운영 확장

- 관리자 2단계 인증 (2FA)

---

## 현재 확정된 주요 제품 판단

### 1. 위치 정보는 모임에 둔다

실제 운영 언어도 “그룹 장소”보다 “모임 장소”에 가깝기 때문에,
위치의 소유권은 `Meeting`이 가진다.

### 2. 그룹은 1건의 대표 연락처를 갖는다.

예외 연락처는 `Meeting.contactPhoneOverride`로만 처리한다.

### 3. 공개 사이트 테마는 preset theme id 기준으로 운영한다

현재는 자유 편집형 테마 에디터보다
`draft / publish / rollback` 가능한 preset 선택 구조를 우선한다.

### 4. 테스트 도구는 상시 CRUD와 분리한다

정제 import와 좌표 보정은 자주 쓰는 관리 기능이라기보다
운영 지원 도구에 가깝기 때문에 별도 화면에 둔다.
